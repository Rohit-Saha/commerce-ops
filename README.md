# commerce-ops

Event-Driven Order & Inventory Management System.

Orchestrated microservices (Order → Inventory → Payment → Shipping) over Kafka, with saga compensation, Redis caching/rate limiting, and a live React admin console.

## Status

Scaffolding in progress. See `docs/` once the Phase 1 MVP is ready.
